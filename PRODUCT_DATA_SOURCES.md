# Product data sources

The expanded catalog uses real product families/names from manufacturer catalogs. Product imagery in this static build uses the real product-photo assets already present in the Power Tools project.

Official manufacturer references used while validating product naming:

- Bosch Professional Egypt: https://www.bosch-professional.com/eg/en/
- Bosch Professional Egypt — Metalworking: https://www.bosch-professional.com/eg/en/metalworking-227130-ocs-c/
- Bosch Professional Egypt — Saws: https://www.bosch-professional.com/eg/en/saws-131408-ocs-c/
- DEWALT — DWE402: https://www.dewalt.com/en-us/product/dwe402/4-12-115mm-small-angle-grinder
- STANLEY — FATMAX Tape Measure: https://www.stanleytools.com/products/hand-tools/tape-measures/fatmax-tape-measure/25-ft-fatmax-autolock-tape-measure/fmht33338
- 3M Safety Glasses catalog: https://www.3m.com/3M/en_US/p/c/ppe/eye-protection/glasses/
- 3M Manufacturing Tape catalog: https://www.3m.com/3M/en_US/p/c/tapes/b/scotch/i/manufacturing/

No prices are invented in the catalog; customers are directed to WhatsApp for price and availability.
