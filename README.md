# Power Tools Landing Page

واجهة عربية RTL متجاوبة لموقع Power Tools، مبنية بـ HTML + CSS + JavaScript فقط، بدون Framework.

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح، أو استخدم Live Server في VS Code.

## رفعها على GitHub Pages
1. أنشئ Repository جديد على GitHub.
2. ارفع `index.html` و`style.css` و`script.js` ومجلد `assets`.
3. من Settings → Pages اختر Deploy from a branch ثم `main` و`/root`.
4. احفظ وانتظر رابط الموقع.
